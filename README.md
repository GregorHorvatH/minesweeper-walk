# Minesweeper Walk

Браузерна гра на TypeScript + Phaser 4: пройдіть мінним полем з верхнього лівого кута до хатинки в правому нижньому.
Є два режими гри (обираються в меню, прогрес і рекорди в кожному свої):

- **Додому (home run)** — дійти до хатинки в правому нижньому куті; прохід гарантовано безпечний.
- **Сапер (minesweeper)** — хатинки немає; потрібно позначити прапорцями **всі** міни. Зараховується, лише якщо прапорці стоять рівно на мінах і **немає жодного зайвого**. Підірвана міна теж вважається знайденою (але коштує життя).

Цифра в клітинці, де ви стоїте, показує, скільки мін навколо (8 сусідів). Відкриті клітинки лишаються — прокладайте безпечний шлях.
Повний опис і план — у [doc/GAME-PLAN.md](doc/GAME-PLAN.md).

## Запуск

```bash
npm install
npm run dev      # розробка, http://localhost:5173
npm test         # Vitest: генератор, правила, рекорди
npm run build    # перевірка типів + збірка в dist/
```

## Публікація на itch.io

```bash
npm run package:itch   # збірка + minesweeper-walk-itch.zip (index.html у корені архіву)
```

Оновлення збірки з терміналу (потрібен [butler](https://itch.io/docs/butler/), вхід через `butler login`; сторінка проєкту вже створена):

```bash
ITCH_TARGET=ваш-логін/назва-гри npm run publish:itch   # збірка + butler push у канал html5
```

Butler оновлює лише файли гри; опис, обкладинку й налаштування сторінки змінюють на сайті.

На itch.io: **Create new project → Kind of project: HTML**, завантажте `minesweeper-walk-itch.zip`, позначте *This file will be played in the browser*. Рекомендований Viewport size — 960×640 (або ввімкніть Fullscreen button); у налаштуваннях сторінки варто ввімкнути *Mobile friendly*, бо гра має тач-керування. Шляхи в збірці відносні (`base: './'`), тож гра працює з будь-якого підкаталогу. Параметри `?seed=` / `?level=` на itch.io недоступні (гра вбудована в iframe), але прогрес, рекорди й налаштування зберігаються в `localStorage`.

| Іти до відкритої клітинки | клік по ній | тап по ній |

| Відкрити ящик під персонажем | `O` | кнопка «📦 Відкрити» над підказкою |
| Предмет «в руку» (далі стрілка / тап по клітинці задає напрямок; повторне натискання — скасувати) | `1` камінь, `2` палка з чобітком, `3` кірка | тап по слоту в смузі інвентаря |
| Режим огляду: поки тримаєте `Shift`, стрілки рухають жовтий курсор, `F` змінює прапорець будь-де; відпустили `Shift` — вихід | `Shift` + стрілки, `F` | довгий тап по будь-якій клітинці |
| Масштаб | `-` / `+` (також цифрова клавіатура), `Ctrl` + колесо | щипок двома пальцями (масштаб липне до найближчого кроку) |
| Прокрутка карти | перетягування лівою кнопкою миші, колесо / тачпад (`Shift` + колесо — по горизонталі) | два пальці |
| Камера назад до персонажа | будь-який крок | кнопка 🎯 внизу праворуч, тап по персонажу, будь-який крок |
| Вибір рівня (будь-який, до якого вже дійшли) | `L`, стрілки, `Enter`; `Esc` — закрити | тап по «Рівень N ▾» у верхній панелі |
| Рівень заново | `R` | — |
| Вимкнути/увімкнути весь звук одразу (музика + ефекти) | `S` або іконка 🔊 в HUD | іконка 🔊 в HUD |
| Меню (грати, нова гра, вибір рівня, налаштування) | `M` або `Esc`, кнопка ☰ у HUD | кнопка ☰ у HUD |

## Прапорці

Кожне натискання `F` (чи права кнопка / довгий тап) на клітинці змінює колір по колу:

| Колір | Значення | Пускає на клітинку? |
|-------|----------|---------------------|
| 🔴 червоний | небезпека (тут міна) | ні |
| 🟡 жовтий | підозра | ні |
| 🟢 зелений | безпека | так |
| — | прапорець знято | так |

У режимі «Сапер» міною вважається лише **червоний** прапорець: перемога, коли червоні стоять рівно на всіх мінах і ніде більше. Жовті й зелені на перемогу не впливають (але зелений на міні перемоги теж не дає — міна лишається непозначеною). Лічильник 🚩 у HUD показує кількість червоних.

## Вибухова хвиля

Коли міна вибухає (ви ступили на неї, її підірвали камінь, палка чи вихід з тунелю кіркою), хвиля **відкидає персонажа на 1 клітинку** від міни — по прямій, від міни до вас. Це залежить від галочки в налаштуваннях **«Хвиля відкидає лише на відкриту клітинку»** (за замовчуванням увімкнена, діє одразу):

- **☑ увімкнена** — кидає лише на вже відкриту клітинку (вона безпечна). Якщо позаду закрита клітинка, персонаж лишається на місці.
- **☐ знята** — може закинути і на ще **не відкриту** клітинку: вона відкриється (з каскадом нулів); якщо там міна — вона теж вибухає (ще −1 життя, без нової хвилі), а якщо хатинка в режимі «Додому» — перемога.

Край поля хвилю гасить завжди. Після остаточної втрати життя хвилі немає.

## Ящики зі скарбами

На полі лежать ящики — **лише на клітинках без мін**. Ящик видно, тільки коли клітинка відкрита (інакше він би виказував, що там безпечно). Станьте на клітинку з ящиком і натисніть `O` — вміст потрапить в інвентар (смуга внизу екрана; за замовчуванням інвентар на кожному рівні починається порожнім; галочка в налаштуваннях «Переносити інвентар на наступний рівень» зберігає знайдене після перемоги (повторна спроба після поразки чи `R` стартує з тим, що було на початку рівня, а вибір рівня в меню — з порожнім)).

| Предмет | Що робить |
|---------|-----------|
| 🪨 Камінці (2–4 з ящика) | Кинути на **сусідню** клітинку: міна вибухне без втрати життя й зникне (цифри навколо перерахуються), безпечна клітинка відкриється. Один камінь — одна клітинка, потім закінчуються |
| 🥾 Палка з чобітком на мотузці | Перевірити **одну сусідню** клітинку: безпечна відкриється (палка ціла, можна знову), а на міні міна **вибухає** (без втрати життя), палка **ламається**. Прапорець на перевіреній клітинці знімається |
| ⛏ Кірка | Пробити тунель під сусідньою клітинкою (навіть із міною) і вийти на **наступній** — через одну від персонажа. Після використання кірка непридатна. Якщо вийшли на міну — вибух, як при кроці |

Предмет не витрачається, якщо застосувати його на вже відкриту клітинку чи за межі поля.

## Факел

Персонаж тримає в правій руці анімований факел: полум'я мерехтить і відхиляється проти напрямку руху, навколо м'яке світіння, час від часу злітають іскри. Усе малюється кодом (без асетів).

Іконка вкладки (favicon) — той самий персонаж із факелом: `public/favicon.svg` плюс PNG 32×32 і 180×180 для браузерів без підтримки SVG та для iOS.

## Могилка

Коли життя скінчились, персонаж зникає, а на клітинці з міною, де він підірвався, падає маленька могилка. На ній горить свічка — символ факела, який герой ніс за життя. Екран поразки відсувається так, щоб не закривати могилку; замість значка вибуху біля заголовка горить така сама свічка.

## Звук і музика

Усе синтезується кодом (Web Audio), без аудіофайлів. Фонова музика — повільна, трохи тривожна й така, що **еволюціонує**: 128 тактів (≈ 6 хв 45 с) до першого повтору. Це 8 розділів по 16 тактів, кожен із власною послідовністю акордів (ля мінор, ре мінор, мі мінор, андалузька каденція, спокійна «майже без руху» і світліша до мажорна, повернення до ля мінору), а кожну послідовність зіграно двічі з різною фактурою: інший малюнок арпеджіо, щільність і регістр, розкладка пада, «енергія», довга мелодія та коротка «луна» в середині такту. Шари: пад, бас, розріджене арпеджіо й мелодія з легкою луною. Партитура детермінована (`src/musicScore.ts`) і покрита тестами.

### Музика реагує на гру

Настрій змінюється на межі такту (і лише якщо тримається щонайменше два такти — одноразові стрибки не смикають музику), з плавною зміною фільтра й «луни»:

| Настрій | Коли | Як звучить |
|---------|------|-----------|
| **Піднесений** | «Додому»: відкрилась суцільна дорога з відкритих клітинок до хатинки; «Сапер»: знайдено ≥ 70% мін без хибних червоних прапорців; перемога | мажорніші акорди, жвавіший темп, вище й густіше арпеджіо, більше мелодії, світліший фільтр |
| **Похмурий** | складний вибір: жоден хід не виводиться логікою з цифр (власний розв'язувач сапера), а каменя чи палки в запасі немає; поразка | мінорніші та зменшені акорди, повільніший темп, рідше арпеджіо, низька «педаль» під тактом, глухіший фільтр, довша луна |
| Звичайний | решта | основна тема |

Прапорці гравця для аналізу ігноруються (вони можуть бути хибні), справжніх мін розв'язувач не підглядає.

## Меню та налаштування

Гра стартує зі стартового меню: «Грати / Продовжити (рівень N)», «Нова гра», «Обрати рівень», «Режим», «Довідка», «Налаштування».
**Довідка** — п'ять розділів (правила, режими, прапорці, інвентар, керування); ← / → або клік по верхній кнопці перемикають розділ, `Esc` — назад до меню. Під час гри меню відкривається клавішею `M` (або `Esc`) чи кнопкою ☰, а «Повернутися до гри» продовжує з того ж місця.
Режим гри (Додому / Сапер) обирається рядком «Режим» у меню.
Налаштування: мова (українська / English), галочки «Фонова музика» та «Звукові ефекти», кількість життів (1 / 3 / 5, діє з наступної гри), галочки «Хвиля відкидає лише на відкриту клітинку» та «Переносити інвентар на наступний рівень». Усе зберігається в браузері.
Літера `S` перемикає весь звук (якщо щось грає — вимикає і музику, і ефекти, інакше вмикає обидва), тому рух — лише стрілками (WASD не використовується).

## URL-параметри

- `?seed=123` — фіксоване поле (однакове для всіх, «ще раз» повторює те саме).
- `?level=5` — почати з потрібного рівня.
- Будь-який із цих параметрів пропускає стартове меню.
